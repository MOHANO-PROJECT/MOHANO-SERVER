매칭 후보 노출·응답 가능성 기준
===============================

목적
----
온보딩을 마친 정상 사용자를 매칭 후보에서 임의로 제외하지 않으면서, 응답 가능성이 높은 상대를
먼저 제안한다. FCM 알림을 누르고 앱을 여는 시간까지 고려해 통화 신청은 생성 후 15초 동안 유효하다.

현재 후보 자격
--------------
후보는 아래 조건을 모두 만족해야 한다.

1. 본인이 아니어야 한다.
2. 계정 상태가 `active` 또는 로컬 개발용 `seed`여야 한다.
3. 온보딩 프로필이 완료되어야 한다.
4. 요청자의 1인칭 조건인 국가·성별·연령 범위에 맞아야 한다.
foreground 상태, 통화 알림 권한, FCM/APNs token 유무는 후보 자격 조건이 아니다. 알림을
허용하지 않은 사용자도 후보에 남는다. 서버는 동일한 노출 이력 그룹 안에서 아래 순서로만 내부
정렬한다.

1. 최근 5분 안에 앱이 foreground 전환을 단발성으로 보고한 사용자
2. 통화 알림 동의와 유효한 push token이 있는 사용자
3. 그 외 사용자

연령 비표시 사용자의 실제 연령은 4번 필터에만 쓴다. 공개 후보 응답의 `age`는 null로
반환하므로 카드에는 표시하지 않는다.

통화 신청 시 재검사
-------------------
후보 목록을 받은 시점과 통화 신청 시점 사이에는 상태가 바뀔 수 있다. 따라서
`POST /v1/call-requests`는 대상의 계정·프로필·제한 상태를 다시 검사한다. 실패하면
`409 candidate_unavailable`을 반환하며 앱은 다음 후보로 이동할 수 있다.

데이터와 API
------------
- `users.last_active_at`: 앱의 마지막 foreground 전환 시각. background 전환 때 null로 비우며,
  비정상 종료 뒤에는 최대 5분 동안의 정렬 힌트로만 취급한다.
- `users.call_notifications_enabled`: 통화 알림 수신 동의
- `users.push_token`: FCM/APNs 전달에 사용할 현재 기기 token. 공개 API나 로그에 넣지 않는다.
- `PUT /v1/me/availability/presence`: 앱의 home 진입·foreground 복귀·background 전환·로그아웃에
  맞춰 `is_foreground`를 한 번씩 갱신한다. timer나 polling으로 호출하지 않는다.
- `PUT /v1/me/availability`: 알림 동의와 token을 등록·갱신·폐기한다.

Flutter 동작
-----------
- 로그인 복원, 로그인 완료, 온보딩 완료 후 home 상태가 되면 foreground 상태를 한 번 보낸다.
- foreground 복귀 시 true, background·inactive·detached·로그아웃 시 false를 각각 한 번 보낸다.
- 반복 heartbeat, polling, 타이머 기반 presence 요청은 사용하지 않는다.

로컬 개발
---------
- `seed` 후보에는 개발 중 매칭이 비지 않도록 알림 동의와 로컬 전용 token을 부여한다.
- 실제 사용자는 Firebase token이나 알림 권한이 없어도 후보에 남는다.

후속 구현
---------
- Firebase Cloud Messaging(Android) 및 APNs(iOS) 초기화, OS 권한 요청, token 등록·회전·폐기
- token을 기기별로 분리한 `notification_devices` 테이블 전환. 현재는 MVP 단일 token 구조다.
- 실제 통화 신청 push 발송, 실패 token 자동 폐기, 재시도·rate limit, 전송 결과 관측
- 수신자 앱의 통화 신청 inbox 갱신과 push를 통한 수락 화면 진입
- 사용자별 통화 수신 가능 시간대·방해 금지 시간·하루 수신 횟수 제한
- 차단·신고·탈퇴·운영 제한 상태를 후보 SQL과 통화 신청 재검사에 반영
- 최근 통화·거절·무응답 이력 기반의 재노출 간격과 품질 점수
- foreground/알림 가능 여부를 공개 프로필에 표시할지 여부와 개인정보 정책 검토
- 다중 기기와 동시 세션의 정확한 presence 집계
