광고 개인화 선택 API
====================

변경 목적
---------
광고 SDK를 도입하기 전에 사용자의 맞춤형 광고 동의 여부를 영속화하고,
이후 설정에서 철회·변경할 수 있는 API 기준을 마련한다.

확정한 결정
-----------
- 광고 선호도는 필수 이용약관·개인정보처리방침 동의와 분리된 선택값이다. 맞춤형 광고 거절은
  서비스 이용 제한 사유가 아니다.
- `personalized_ads_allowed=true`는 향후 광고 식별자를 개인화 광고에 사용할 수 있다는 동의이고,
  `false`는 동의하지 않은 경우의 일반(비개인화) 광고 기준이다.
- `advertising_consent_decisions`는 append-only다. 변경할 때마다 새 행을 추가하며, 가장 최근
  `decided_at` 이력이 현재 선택이다. 정책·SDK가 바뀌어도 당시 선택을 설명할 수 있도록
  consent version·표시 언어·시각을 함께 보관한다.
- 계정 삭제 시 광고 선호도 이력도 제거한다. 광고 SDK, AD_ID, IDFA, 실제 광고 식별자는 이 서버에
  저장하거나 중계하지 않는다.

API·데이터 요구사항
--------------------
- `GET /v1/me/advertising-consent`: 현재 선택을 반환하고, 선택 이력이 없으면 204를 반환한다.
- `PUT /v1/me/advertising-consent`: `{ personalized_ads_allowed: boolean, locale: en|ja|ko }`를
  저장하고 최신 선택을 반환한다.
- 테이블: `advertising_consent_decisions(id, user_id, consent_version,
  personalized_ads_allowed, locale, decided_at)`.
- `20261026_0010_advertising_consent_decisions` migration이 테이블과 조회 인덱스를 생성한다.

다음 작업 또는 미결정 사항
----------------------------
- 앱 설정 화면은 조회·변경 API를 사용해 선택을 철회하거나 바꾼다.
- 광고 제공자와 SDK를 확정한 뒤, 실제 광고 요청 전에 OS·국가별 동의 상태와 이 선택을 함께
  적용한다. iOS ATT, EEA UMP/TCF 등은 이 API만으로 충족되지 않는다.
- 개인정보처리방침·스토어 Data Safety·광고 파트너 목록·보존 기간·15세 이상 사용자에 대한
  국가별 개인화 제한을 출시 법률 검토에서 확정한다.
